# Dark Souls: Remastered game profile (`01004AB00A260000`)

This checkout contains one supported game profile:
`dm/games/01004AB00A260000/`. The directory name is the base game's title ID.
All game-specific constants and generated shader data belong here; shared host
code must not grow another title-specific constant when a profile value is enough.

The profile contains:

- `game.tsv`: identity, supported NSO builds, loaded modules, memory layout,
  NVN bindings and Mac input settings.
- `shader_map.tsv`, `shader_facts.tsv`, `shader_pairs.tsv` and the optional
  `shader_facts_manual.tsv`: shader translation facts for the base game and
  update 1.0.3.
- `c1_full.tsv`: the checked shader-library inventory regenerated by
  `c1_guard.py`.
- `pso_manifest.tsv` and `bf_want.tsv`: pipeline prewarm and bindless-fetch
  data.
- `dmsh_chain.h`: the shader translation-chain version generated by
  `dmsh_chain.py --header`.
- `frame_limiter.json`: build-bound expected instructions for the explicitly selected
  experimental 60 Hz limiter argument; no automatic game-code cut.
- `bringup.md`: title-specific bring-up evidence and known gaps.

## Consumers

| Consumer | Selection | Profile data |
|---|---|---|
| Shader tools | `DM_GAME=01004AB00A260000` | shader tables and `nvn_*` / `shader_*` keys |
| Mac host and tests | `GAME=01004AB00A260000` | generated `game_profile.h` and shader chain |
| iOS packer | `GAME=01004AB00A260000` | app identity, modules, RomFS marker and tables |
| `scripts/build_ipa_from_nsp.py` | NSP base title ID | the same profile |

The profile loader defaults to this title and rejects every other title ID.
The command-line interface is:

```sh
python3 dm/games/game.py list
python3 dm/games/game.py 01004AB00A260000 modules
python3 dm/games/game.py header 01004AB00A260000 dm/host/gen/01004AB00A260000/game_profile.h
```

## Build rows

`game.tsv` currently accepts the base game (`v0`, display version 1.0.0) and
the 1.0.3 update (`v196608`). The `main`, `subsdk0` and `sdk` build IDs are
checked before rewriting. Do not let a fixed address run on an unregistered
build; carry a new build with `dm/tools/nso_fnmap.py` and verify it by
disassembly first.

## Shader chain

When a shader-chain input changes, run the target profile procedure from the
repository root:

```sh
DM_GAME=01004AB00A260000 python3 dm/gfx/tools/dmsh_chain.py --header
DM_GAME=01004AB00A260000 python3 dm/gfx/tools/dmsh_build.py <shader-pkg> <cache>
python3 dm/gfx/tools/c1_guard.py <cache>/b-<chain> dm/games/01004AB00A260000/c1_full.tsv
make -C dm/host GAME=01004AB00A260000 dmhost
```

Build iOS shader libraries with `IOSOUT=<directory>` in the `dmsh_build.py`
command. Keep all generated packages, caches and libraries in the game's work
folder, not in this repository.

## Profile keys

The important keys in `game.tsv` are:

| Key | Meaning |
|---|---|
| `title_id`, `program_id`, `name`, `ipa`, `bundle_id`, `app_category` | Target title identity and app metadata; `bundle_id` is the default application identity shared by all packers |
| `build` | supported version, display version and module build IDs |
| `package`, `shader_versions`, `modules`, `romfs_marker` | package selection, shader inputs, module load order and extraction marker |
| `mem_reserve`, `mem_alias`, `mem_stack`, `app_pool` | guest address-space partition and application pool |
| `device_api`, `shared_font`, `pad_layout`, `mac_layout`, `mac_mouse_sensitivity` | SDK/NVN compatibility, font representation and input defaults |
| `nvn_*`, `shader_*` | shader binding layout and extraction groups |

The translator and host consume these values through generated headers and the
profile's shader tables. There is no second profile or survey mode in this
repository.
